# Sovereign Gods ⚔️

![GitHub Issues](https://img.shields.io/github/issues/ereb0s-games/master-mayhem)
![GitHub commits since latest release](https://img.shields.io/github/commits-since/ereb0s-games/master-mayhem/latest)

> "Sculpt nothing into something, something worth suffering for."

A fast, momentum-based multiplayer combat game built in the **Godot Engine** by [Erebos Games](https://github.com/Ereb0s-Games). Master your movement, master your blade, master the mayhem.

> **Repo note:** This is the working repository (`master-mayhem`) for **Sovereign Gods**. The game is in active, early development.

---

## ✨ Features

- **Momentum-based movement** — traversal that rewards speed and flow, including wall-jumping for vertical, high-tempo play.
- **Fluid sword combat** — responsive melee built around timing, spacing, and momentum.
- **Custom level editor** — build, tweak, and share your own arenas.
- **Dedicated multiplayer** — a Docker-hosted dedicated server for consistent, low-friction online matches.

---

## 🛠 Tech Stack

- **Engine:** Godot
- **Languages:** GDScript, GDShader
- **Server:** Docker (dedicated server hosting)

## 🚀 Getting Started

**Prerequisites:** A recent version of the [Godot Engine](https://godotengine.org/).

1. Clone the repository:
   ```bash
   git clone https://github.com/ereb0s-games/master-mayhem.git
   ```
2. Open **Godot**, choose **Import**, and select the `project.godot` file.
3. Press **Play** to run the game locally.
